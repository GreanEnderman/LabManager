# QA-P1-04 数据导入验证清单

## 1. 验证目标

- 验证手工录入和批量导入共用同一入口
- 验证导入结果反馈、错误清单、历史记录和最新成功记录展示
- 验证普通成员仅可查看，不可执行导入

## 2. 环境准备

- 进入 `数据导入` 页面
- 默认角色切换为 `管理员`
- 先分别检查 `化学品` 和 `设备` 两个实体视图

## 3. 用例

### 用例 1：化学品手工录入成功

步骤：

1. 保持实体类型为 `化学品`
2. 保持来源为 `手工录入`
3. 填写 1 条记录，名称为 `乙醇`，库存 `8`，阈值 `5`
4. 点击 `提交录入`

预期：

- 最近一次导入结果显示 `成功 1 条，失败 0 条`
- 导入历史新增 1 个批次
- 最新成功记录中出现 `乙醇`

### 用例 2：化学品批量导入包含重复记录

步骤：

1. 切换来源为 `批量导入`
2. 点击 `加载示例数据`
3. 点击 `执行导入`

预期：

- 最近一次导入结果显示 `成功 1 条，失败 1 条`
- 错误清单中出现 `duplicate_record`
- 导入历史新增 1 个 `部分失败` 批次
- 规则事件数量大于等于 `1`

### 用例 3：设备批量导入成功

步骤：

1. 将实体类型切换为 `设备`
2. 点击 `加载示例数据`
3. 手动修正第二行 `记录 ID`，避免重复
4. 点击 `执行导入`

预期：

- 最近一次导入结果显示 `成功 2 条，失败 0 条`
- 导入历史中设备批次数量增加
- 最新成功记录中出现对应设备

### 用例 4：普通成员只读权限

步骤：

1. 将左侧角色切换为 `普通成员`
2. 进入 `数据导入` 页面

预期：

- 页面显示只读提示
- 行编辑区不可编辑
- 不显示 `提交录入` / `执行导入` / `添加一行` 按钮
- 仍可查看导入历史、结果摘要、错误清单和最新成功记录

## 4. 验收结论

- 以上 4 组用例全部通过后，可判定 `QA-P1-04` 达标
