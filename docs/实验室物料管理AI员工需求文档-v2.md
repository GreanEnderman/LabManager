# 实验室物料管理 AI 员工需求文档 V2

## 1. 项目目标

建设一套面向实验室物料、化学品、仪器设备和 AI 员工流程的管理系统，帮助实验室完成库存管理、设备维护、任务跟进、审批、报告和风险分析。

AI 员工的定位是流程协助者，不是自由聊天助手。核心链路是：

`巡检 -> 发现问题 -> 生成任务 -> 跟进处理 -> 审批 -> 报告 -> 复盘分析`

## 3. 本次新增需求

### 3.1 化学品增加采购链接

状态：待实现

需求点：

- 在化学品管理中，每个化学品旁边可以维护采购链接。
- 一个化学品至少支持一个采购链接。
- 采购链接用于后续补货和自动采购流程。
- 化学品列表中应能直接看到是否已配置采购链接。
- 已配置采购链接时，用户可以点击打开。
- 未配置采购链接时，系统应提示“未配置采购链接”。
- 采购链接需要支持新增、修改、删除。

建议字段：

- 化学品 ID
- 化学品名称
- 采购链接
- 供应商名称
- 是否默认采购链接
- 最近更新时间

### 3.2 阈值下化学品自动采购

状态：待实现

需求点：

- 当化学品库存低于或等于阈值时，系统自动识别为低库存。
- 如果该化学品已配置采购链接，系统可以自动生成采购任务。
- 系统根据当前库存和阈值计算建议采购数量。
- 自动采购前应检查是否已有未完成的采购任务，避免重复采购。
- 自动采购动作需要进入 AI 任务和日志。
- 高风险化学品、受控化学品或金额较高的采购必须进入人工审批。
- 自动采购成功后，采购任务状态更新为已提交或处理中。
- 到货入库后，库存数量更新，采购任务关闭。

自动采购最小流程：

1. 检查库存是否低于阈值。
2. 检查是否配置采购链接。
3. 检查是否已有未完成采购任务。
4. 生成采购任务。
5. 判断是否需要审批。
6. 审批通过或满足自动规则后提交采购。
7. 记录采购结果。

### 3.3 维修报告上传后自动更新设备状态

状态：待实现

需求点：

- 在仪器设备维护记录中支持上传维修报告。
- 维修报告可以关联到具体设备。
- 上传维修报告后，系统根据报告结果更新设备状态。
- 如果报告结果为维修完成，设备状态更新为正常。
- 如果报告结果为仍需维修，设备状态更新为待维护。
- 如果报告结果为故障未解决，设备状态保持故障。
- 关键设备从故障恢复为正常时，需要人工确认或审批。
- 状态更新必须写入日志。
- 关联的 AI 维修任务应同步更新状态。

支持的报告信息：

- 设备 ID
- 设备名称
- 维修日期
- 维修人员
- 维修结果
- 报告附件
- 备注说明

### 3.4 根据一段时间日报分析未来问题

状态：待实现

需求点：

- 系统可以选择一段时间的日报作为分析范围。
- 支持按最近 7 天、30 天、90 天进行分析。
- 系统根据日报、任务、库存、设备维护记录分析未来可能发生的问题。
- 分析结果需要列出风险原因。
- 分析结果需要给出建议处理动作。
- 分析结果可以转成 AI 任务。
- 分析结果可以进入风险专题报告。

需要分析的问题类型：

- 哪些化学品可能即将低库存。
- 哪些设备可能即将维护超期。
- 哪些设备近期故障频率较高。
- 哪些任务可能超时。
- 哪些审批可能形成积压。

输出内容：

- 风险名称
- 风险来源
- 风险等级
- 可能发生时间
- 依据数据
- 建议动作
- 是否需要创建任务

## 5. 验收标准

### 化学品采购链接

- 每个化学品可以维护采购链接。
- 化学品列表能看到采购链接状态。
- 点击采购链接可以打开对应页面。
- 链接修改后有记录。

### 自动采购

- 库存低于阈值时能生成采购任务。
- 已有未完成采购任务时不会重复生成。
- 需要审批的采购不会直接自动提交。
- 采购动作有日志记录。

### 维修报告

- 设备维护记录可以上传维修报告。
- 报告上传后能关联到设备。
- 系统能根据维修结果更新设备状态。
- 设备状态变化有日志记录。

### 日报风险分析

- 可以选择时间范围生成分析结果。
- 分析结果能说明未来可能发生的问题。
- 每条风险都有依据和建议动作。
- 风险可以转为 AI 任务。

## 6. 暂不实现

- 不实现自由聊天式 AI 助手。
- 不直接接入真实支付。
- 不绕过审批自动采购高风险化学品。
- 不在没有维修结果依据时自动恢复设备状态。
- 不让 AI 直接决定权限、审批或最终采购规则。
