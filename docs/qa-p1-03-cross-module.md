# QA-P1-03 跨模块联调测试清单

## 1. 验证目标

- 验证 `Dashboard / AlertCenter / 数据导入 / AI 模块 / SystemSettings` 在 P1 阶段的主链路联动
- 验证从业务侧进入 AI 闭环时，状态、入口和权限提示保持一致
- 验证管理员与普通成员在跨模块场景下的操作边界

## 2. 预置条件

- 角色默认为 `管理员`
- 已完成至少一轮导入，确保 `数据导入` 页面已有批次记录
- AI 驾驶台、任务中心、审批台、报告中心已有可展示的 mock 或运行态数据

## 3. 用例

### 用例 1：首页 AI 摘要跳转闭环

步骤：

1. 进入 `首页概览`
2. 查看 `AI 今日工作摘要`
3. 点击 `前往 AI 驾驶台`

预期：

- 首页显示事件数、任务数、审批数、报告数和高优任务数
- 点击后跳转到 `AI 驾驶台`
- 驾驶台中的摘要指标与首页口径一致

### 用例 2：预警中心到 AI 任务中心

步骤：

1. 进入 `预警中心`
2. 在低库存、待维护设备或异常设备区选择一条未建任务的记录
3. 点击 `生成任务` 或 `立即处理`

预期：

- 页面跳转到 `AI 任务中心`
- 任务列表中出现对应来源对象的任务
- 同一来源对象再次回到预警中心时，入口切换成 `查看任务`

### 用例 3：数据导入到规则结果感知

步骤：

1. 进入 `数据导入`
2. 选择 `化学品` + `批量导入`
3. 加载示例数据并执行导入
4. 回到 `首页概览`、`预警中心`、`AI 驾驶台`

预期：

- 数据导入页面展示成功数、失败数、错误清单和导入历史
- 最近一次导入结果中存在规则事件数量
- 回到首页、预警中心和 AI 驾驶台时，可以感知到对应低库存/异常事件仍处于主链路中

### 用例 4：系统设置只读边界

步骤：

1. 切换到 `普通成员`
2. 进入 `系统设置`
3. 再进入 `数据导入` 和 `预警中心`

预期：

- 系统设置仅显示查看态，不显示编辑、新增、删除按钮
- 数据导入页不显示 `提交录入` / `执行导入` / `添加一行`
- 预警中心不显示可写动作，改为只读提示

### 用例 5：AI 驾驶台到报告/审批联动

步骤：

1. 进入 `AI 驾驶台`
2. 点击 `生成日报`
3. 点击进入 `AI 报告中心`
4. 如存在高风险任务，进入 `AI 审批台`

预期：

- 驾驶台可以直接触发日报生成
- 报告中心可看到新增的报告结果
- 待审批事项可在审批台查看并处理

## 4. 验收结论

- 上述 5 组用例全部通过后，可判定 `QA-P1-03` 达标
