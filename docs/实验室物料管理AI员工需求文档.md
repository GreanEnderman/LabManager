# 实验室管理系统简明需求文档

## 1. 项目目标

搭建一套面向实验室日常运营的管理系统，实现库存、设备、维护、任务、预警与报表的统一管理，提升流程透明度、处理效率和管理闭环能力。

## 2. 建设范围

- 物料/化学品库存管理
- 设备台账与维护管理
- 任务流转与处理跟踪
- 异常预警与主管审批
- 报表生成与邮件自动发送

## 3. 角色定义

- 录入人员：维护基础数据、导入 Excel、提交业务记录
- 仓管/设备管理员：处理库存与设备相关任务
- 主管：审批高风险事项、接收报告邮件
- 系统管理员：维护规则、权限、通知配置

## 4. 核心业务流程

### 4.1 数据录入流程

**输入：**

- 手工录入表单
- Excel 导入文件

Excel 表格建议字段如下：

| 字段 | 说明 |
|---|---|
| 记录编号 | 唯一标识 |
| 物料/设备名称 | 名称信息 |
| 分类 | 化学品、耗材、设备等 |
| 规格型号 | 规格或型号 |
| 当前数量 | 当前库存/数量 |
| 安全阈值 | 预警下限 |
| 状态 | 正常、低库存、待维护、停用等 |
| 所属实验室 | 所属部门/实验室 |
| 责任人 | 当前负责人 |
| 更新时间 | 最近更新时间 |
| 备注 | 补充说明 |

**处理过程：**

1. 用户上传 Excel 或填写表单
2. 系统进行字段校验、格式校验、重复校验
3. 合法数据写入业务数据库
4. 异常数据生成错误清单并反馈用户修正

**输出：**

- 入库成功的数据记录
- 导入结果反馈
- 错误明细清单

### 4.2 规则识别与事件触发流程

**输入：**

- 库存数据
- 设备状态数据
- 维护计划数据
- 任务处理状态数据

**处理过程：**

1. 系统按预设规则识别异常
2. 生成标准化事件，如低库存、维护逾期、任务超时
3. 按优先级分类，决定进入任务、审批或通知流程

**输出：**

- 异常事件记录
- 待处理任务
- 待审批事项
- 系统通知消息

### 4.3 任务处理与审批流程

**输入：**

- 系统自动生成的任务
- 人工提交的处理申请

**处理过程：**

1. 系统分派给对应责任人
2. 责任人处理并回填结果
3. 涉及高风险/高金额/关键设备事项时提交主管审批
4. 审批通过后继续执行，驳回则退回修改

**输出：**

- 已分派任务
- 审批结果
- 处理结果记录
- 操作日志与审计记录

### 4.4 报告生成与邮件发送流程

**输入：**

- 库存数据
- 设备维护数据
- 任务处理结果
- 审批结果
- 报表周期配置（日报/周报/月报）
- 主管邮箱映射关系

**处理过程：**

1. 系统汇总指定周期内业务数据
2. 自动生成结构化报告
3. 将报告导出为 PDF
4. 根据实验室/部门/责任范围匹配对应主管
5. 通过邮件自动发送 PDF 报告
6. 记录发送状态，失败时支持重试与告警

**输出：**

- PDF 报告文件
- 邮件发送记录
- 发送失败告警
- 主管收件结果反馈

## 5. 功能需求清单

### 5.1 数据管理

- 支持表单录入与 Excel 批量导入
- 支持数据校验、去重、错误反馈
- 支持历史记录追溯

### 5.2 库存与设备管理

- 支持库存查询、状态展示、阈值预警
- 支持设备台账、维护计划、维护记录管理
- 支持异常状态标记与跟踪

### 5.3 流程与任务管理

- 支持自动生成任务
- 支持任务分派、催办、超时提醒、闭环跟踪
- 支持审批流配置与结果留痕

### 5.4 报表与通知

- 支持日报、周报、月报自动生成
- 支持导出 PDF 报告
- 支持邮件自动发送给对应主管
- 支持通知、发送状态、失败重试记录

## 6. 非功能需求

- 数据准确性：导入校验完整，避免重复和脏数据
- 可追溯性：关键操作、审批、发送过程需留痕
- 可配置性：阈值、审批规则、邮件接收人可配置
- 安全性：按角色控制查看、编辑、审批权限
- 稳定性：报表生成和邮件发送失败需支持重试

## 7. 预期成果

- 建立统一的实验室管理流程
- 减少人工统计与重复沟通成本
- 实现异常自动发现、任务自动流转、报告自动发送
- 让主管及时收到 PDF 报告并快速掌握整体情况
