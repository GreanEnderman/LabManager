# LabManager Project Guidelines

## Communication Language (交流语言)

**Rule:** Always communicate with the user in Chinese (Simplified Chinese).

## Documentation Output Confirmation (文档输出确认)

**Rule:** Before generating any documentation files (e.g., .md, .txt, design docs), ask the user whether they want:
- The content written to a file, or
- The content displayed in the conversation

**Rationale:** Prevents unwanted file creation and gives user control over output format.

## Project Structure (项目结构)

**Official Frontend:** `frontend/` - 正式前端代码库
**Official Backend:** `python_backend/` - 正式后端代码库

**Note:** `backend/` (TypeScript) 是原型参考实现，已不再使用。
